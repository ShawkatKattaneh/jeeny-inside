# Notice

## Jeeny INSIDE

`jeeny-ui-audit` is a project-specific Claude Code skill for Jeeny INSIDE, an independent hackathon concept inspired by Jeeny. Jeeny INSIDE is not an official Jeeny product, and this skill grants no right to use official Jeeny names, logos or assets.

The design values in `references/tokens.md` were extracted from the Jeeny INSIDE Google Stitch exports (Student App, Driver Mode, Operations Dashboard) supplied by the project owner. They describe Jeeny INSIDE's own design and are not licensed for reuse outside this project. The exports themselves are not included in this repository.

Font families (Red Hat Text, Instrument Sans, Spline Sans Mono) and the icon set (Material Symbols) are named in `references/tokens.md` only as the values the Stitch designs specify. No font files, icon files or third-party assets are included, and their use in the application is an open decision (see Unresolved U-1 and U-2 in `references/tokens.md`).
